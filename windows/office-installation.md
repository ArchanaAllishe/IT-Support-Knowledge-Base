# Microsoft Office Installation on Windows

## Purpose

This document provides a standard procedure for installing, activating, and verifying Microsoft Office on Windows computers. It also includes common troubleshooting steps for installation and activation issues.

---

## Scope

This procedure applies to:

* Windows 10
* Windows 11
* Microsoft 365 Apps
* Microsoft Office 2019
* Microsoft Office 2021

---

## Prerequisites

Before beginning the installation:

* Verify the computer is connected to the internet.
* Confirm the user has a valid Microsoft 365 license or Office product key.
* Ensure you have local administrator privileges.
* Verify at least 10 GB of available disk space.
* Close all Microsoft Office applications.
* Remove older or unsupported Office versions if required.

---

## Installation Procedure

### Step 1 – Verify Windows Version

1. Open **Settings**.
2. Select **System** → **About**.
3. Confirm the device is running a supported version of Windows.

---

### Step 2 – Verify Internet Connectivity

1. Open a web browser.
2. Confirm that websites load successfully.
3. Resolve any network connectivity issues before proceeding.

---

### Step 3 – Verify Microsoft License

Confirm the user has an assigned Microsoft 365 license or a valid Office product key.

If the license cannot be verified, contact the Microsoft 365 administrator before continuing.

---

### Step 4 – Download Microsoft Office

Download the installer from the official Microsoft portal or your organization's software distribution platform.

Avoid third-party download sites.

---

### Step 5 – Install Microsoft Office

1. Run the installer using administrative privileges.
2. Accept the license agreement if prompted.
3. Wait for the installation to complete.
4. Do not restart or shut down the computer during installation.

---

### Step 6 – Activate Office

1. Open Microsoft Word.
2. Sign in with the licensed Microsoft account if prompted.
3. Verify that Office reports **Product Activated**.

---

### Step 7 – Install Updates

1. Open any Office application.
2. Navigate to:

```
File
→ Account
→ Update Options
→ Update Now
```

3. Install all available updates.

---

## Verification Checklist

Confirm the following:

* Microsoft Word opens successfully.
* Microsoft Excel opens successfully.
* Microsoft PowerPoint opens successfully.
* Microsoft Outlook opens successfully.
* Office is activated.
* Documents can be created, saved, and reopened.
* No activation or licensing warnings appear.

---

## Common Issues

### Office Installation Fails

Possible causes:

* Previous Office installation
* Insufficient disk space
* Corrupted installer
* Antivirus interference

Recommended actions:

* Restart the computer.
* Remove previous Office versions.
* Run the installer as Administrator.
* Download a fresh installer if necessary.

---

### Office Activation Issues

Possible causes:

* Incorrect Microsoft account
* Missing Microsoft 365 license
* Internet connectivity problems

Recommended actions:

* Verify the correct Microsoft account is being used.
* Confirm the user has an assigned license.
* Sign out and sign back into Office.
* Restart the application and try again.

---

### Outlook Does Not Open

Possible causes:

* Corrupt Outlook profile
* Problematic add-ins
* Mailbox configuration issue

Recommended actions:

* Start Outlook in Safe Mode.
* Create a new Outlook profile.
* Disable unnecessary add-ins.
* Verify mailbox connectivity.

---

## User Communication

After completing the installation, inform the user:

> Microsoft Office has been successfully installed and activated. Word, Excel, PowerPoint, and Outlook were verified to open correctly. If you experience any issues, please contact the IT support team.
