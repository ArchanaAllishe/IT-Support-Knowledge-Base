## Troubleshooting Methodology

Most technical issues are approached using the following process:

1. Understand the reported issue.
2. Gather relevant information.
3. Reproduce the problem when possible.
4. Identify the most likely causes.
5. Test one solution at a time.
6. Verify that the issue is resolved.
7. Document the resolution.
8. Communicate the outcome clearly to the user.
9. Escalate when appropriate.
